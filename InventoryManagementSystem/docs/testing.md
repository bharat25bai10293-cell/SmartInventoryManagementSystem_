# Testing Approach

The project includes a lightweight Java validation test without external frameworks.

Test categories:
1. Product creation with valid values.
2. Duplicate product ID rejection.
3. Negative price rejection.
4. Negative quantity rejection.
5. Stock removal greater than available stock.
6. Billing with insufficient stock.
7. Search for an existing product.
8. Low-stock detection.

The test can be run from the terminal using the commands in README.md.
